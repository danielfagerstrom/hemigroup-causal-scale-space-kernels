# Render-safe LaTeX commands for blueprint statements and proofs (ROADMAP #7 T2).
#
# The transclusion pipeline (LINKAGE.md § cross-repo channel) renders statement/proof
# source to markdown with a pinned pandoc. Pandoc SILENTLY DROPS unknown commands
# outside math — argument and all — and unknown commands inside math reach the reader
# as MathJax errors. So the clean-render gate is source-side: every \command used in a
# statement or proof must be either defined in macros.tex (expanded at render) or
# listed here (vetted standard LaTeX that pandoc/MathJax handle natively).
# check_linkage.py enforces this on every run; it fails the check, the manifest CI,
# and the mathematician's pre-report ritual.
#
# To use a new command: prefer adding a \newcommand to macros.tex (it will expand);
# only vet it here if it is standard LaTeX/AMS that pandoc and MathJax both know.
# One command per line, no backslash. Seeded 2026-07-25 from the full blueprint
# inventory (97 commands, all standard).
#
# 2026-08-07: +22 commands, vetted from the draft's own inventory for the section
# 2-12 transcription (Big Leftarrow Pi bar big cap cdots chi deg downarrow equiv eta
# hat ldots longrightarrow not setminus sup tag varepsilon wedge zeta). `tag` is how
# the blueprint reproduces the draft's hand-numbered equations (6.1), (7.1), (9.1),
# (9.2), which its prose references by number -- \ref would render as a code span.
# `checkmark` appeared in the same diff and was NOT vetted: Example 9.9's tick is
# written out in words instead.
